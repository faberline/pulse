# v0.4 remote executor：只讀工具迴圈候選

Pulse 自己的 Rust 排程隨 `pulse-server serve` 啟動。它沿用 SQLite 任務、run token、預算、device outbox 與恢復。不需要 AW 或額外 VM。工作對應 [#14](https://github.com/faberline/pulse/issues/14) 與 [#16](https://github.com/faberline/pulse/issues/16)，候選為 draft PR #15。

從 repository 根目錄啟動可讀取 private `.env` 的 API keys。其他工作目錄可指定 `PULSE_ENV_FILE` 絕對路徑。環境變數優先，檔案須為 0600，不能是 symlink。預設 `PULSE_PROVIDER=openai` 使用 `gpt-6-luna`；`PULSE_PROVIDER=anthropic` 使用 `claude-haiku-5-5`。沒有自動切換供應商。

```sh
cargo build --locked -p pulse-link --bin pulse-server
PULSE_PROVIDER=openai target/debug/pulse-server serve /PRIVATE/DIRECTORY/server.db 8721
```

## 工具與證據

兩家供應商都使用原生 function calling。每次最多提議一項：`list_files`、`read_text`、`git_status` 或 `git_diff`。參數須符合固定結構。沒有 shell 或寫入工具。local process 另檢查路徑、隱藏檔、敏感名稱、symlink 與檔案類型。

server 在保存提議時核對 task scope、revision、完整 run token、取消狀態與期限。提議只作模型資料，不產生 Human 指令。local 離線或忙碌時，提議保持 waiting_device，idle 不呼叫模型。派工時在同一交易核對 live local lease、工作上限與未決結果，再保存 read intent 與 device outbox。

工具回覆沿用既有 durable receipt。已知結果在同一交易加入 task evidence，並讓原 run 的下一 round 排入佇列。下一次模型請求包含這個 task/revision 的工具呼叫與結果，使用各供應商的原生 tool result 格式。每份模型用證據最多 2,500 bytes，完整原始證據仍在 DB。截斷會明確標示。其他任務的內容不進入 context。

取消、修訂、重啟後的舊 epoch、斷線或 Unknown 結果不會自動續推。重播同一結果不會清掉正在執行的 run。文字回覆保存為 blocked / model_reply_ready，等待接受；模型與工具都不能自行宣告任務成功。

## 費用與恢復

每次最多 1,024 輸出 tokens、32 KiB context、45 秒，HTTP 回應上限 256 KiB。每任務最多 8 次模型呼叫、16 次工具呼叫及 15 分鐘。呼叫前持久預留 US$0.02，沿用每日合計 US$1 與每任務 US$0.25 上限。

本機按 usage 保守結算；它不是供應商帳單。結果不明時保留預留金額並阻擋，不自動重送。固定 call ID 由 run/revision/round 決定，不隨重啟 epoch 改變。已預留而未保存結果的 round 不會再呼叫供應商。已完成的工具讀取不重派。

執行版本改為 `pulse-remote-3`。舊版本中途任務保持 version_incompatible，不自行換版本續跑。

## 2026-11-01 驗證

正常 Rust 測試包含：雙格式工具解析、拒絕額外參數／未知工具／平行呼叫、離線保存與重啟後派工、同任務續推、證據隔離、重複結果、取消／修訂／Unknown／重啟／斷線 fencing。既有 140 個 hard-exit 子程序樣本仍在正常 suite。

另明確執行兩家真實 API：各自提議讀 README，由真正的只讀 Executor 讀目前 Pulse repo，再向同一 run 回覆。每家 2 次模型呼叫、1 次讀檔；最後一輪用量估算 Luna 191、Haiku 418 micro USD。另模擬預留後中斷，核對新 epoch 使用既有 call ID 並 blocked，不再發送請求。此測試手動注入 device receipt，不能取代原生程序驗證。

```sh
PULSE_ENV_FILE=/ABSOLUTE/PATH/.env cargo test -p pulse-link --test remote --locked real_providers_read_local_evidence_and_continue_same_run -- --ignored --nocapture
```

此測試會產生真實 API 用量，正常 CI 不執行。

原生實機另啟動三元件：SwiftUI app、獨立 `pulse-executor` 與 server。兩個角色在 Keychain 保存配對並建立 lease。從單一輸入框送 A（README）及 B（Cargo.toml），各有 2 次 Luna 呼叫與 1 次讀檔，畫面顯示工具證據與有檔案來源的回答。重開 app 並重啟 executor，不傳配對檔，兩者都以 Keychain 既有身分重新連線；epoch 從 1 增至 2。預算列數仍為 6、讀檔仍為 3，沒有重複執行。第三筆為前置 UI 輸入工具的試驗任務；不是 A/B 之一。未改動 Keychain ACL，也沒有明文 fallback。

本機證據位於 private fixture `/private/tmp/pulse-tool-native-n81qo3xn`，API／Rust／Swift／bundle 日誌為 `/private/tmp/pulse-tool-loop-*.log`。這些暫存路徑只供本機查核，不是 CI artifact。
