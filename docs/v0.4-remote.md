# v0.4 remote executor：文字回覆候選

Pulse 自己的 Rust 排程隨 `pulse-server serve` 啟動。它沿用既有 SQLite 任務、run token、預算及恢復，不需要 AW 或額外 VM。

從 repository 根目錄啟動，可讀取 private `.env` 的 API keys。其他工作目錄可指定 `PULSE_ENV_FILE` 絕對路徑。環境變數優先，檔案須為 0600，不能是 symlink。預設 `PULSE_PROVIDER=openai` 使用 `gpt-6-luna`；設定 `PULSE_PROVIDER=anthropic` 使用 `claude-haiku-5-5`。沒有自動切換供應商。

```sh
cargo build --locked -p pulse-link --bin pulse-server
PULSE_PROVIDER=openai target/debug/pulse-server serve /PRIVATE/DIRECTORY/server.db 8721
```

每次只處理一項工作。目前只把當前 task goal 與 task/revision 交給模型，不傳送 repo、key 或其他任務。沒有模型工具或 shell。每次最多 1024 輸出 tokens、45 秒，回覆與 HTTP 資料都有上限。idle 與 blocked 任務不呼叫模型。

呼叫前持久預留 US$0.02，沿用每日 US$1、每任務 US$0.25、每任務 8 次呼叫上限。根據回傳 usage 以短 context 費率保守結算；這是本機估算，不是供應商帳單。無法確認結果時保留預留金額並阻擋，不自動重送。重啟會用穩定 call ID 防止重複計費。

回覆提交時在同一交易核對 revision、epoch、active run、取消與 deadline，保存 checkpoint、對話與任務狀態。舊結果不覆蓋已取消或修改的任務。模型文字只作資料，不能變成人類指令或自動宣告任務成功。文字回覆存好後，task 為 blocked / model_reply_ready，等待後續驗收。

已用兩個獨立小任務實際呼叫 Luna 與 Haiku，確認回覆持久保存、預算 settled 且再次排程不再呼叫。實測用量估算分別 11 與 15 micro USD。驗證命令：

```sh
PULSE_ENV_FILE=/ABSOLUTE/PATH/.env cargo test -p pulse-link --test remote real_providers_save_reply_and_settle_budget -- --ignored --nocapture
```

此測試會產生真實 API 用量，正常 CI 不執行。正常測試另驗取消後的晚到回覆不寫入對話、缺少 provider 的持久等待。
